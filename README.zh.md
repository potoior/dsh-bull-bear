# dsh-bull-bear

> 牛熊行情宠物 — DeepSeek Harness 实时行情状态宠物：组合越接近收益 20%，牛跑得越猛；跌得越深，熊摔得越戏剧。

一个挂在 DeepSeek Harness Web UI 左下角的行情宠物：读**免费实时 A 股行情**，把自选篮的平均涨跌变成一只**奔跑的牛 / 熊**——行情波动越剧烈，它跑得越狂。纯恶搞、无投资建议，仅供自己看着开心。

## 功能

- **实时免费行情**：新浪 `hq.sinajs.cn` 公开接口，免登录、免 API key，Node 直连。
- **组合驱动情绪**：宠物追随**整个自选篮的平均**涨跌——上涨显牛（🐂），下跌显熊（🐻），横盘平静。
- **戏剧化奔跑（vigor 驱动）**：平均涨跌越接近 **20% 收益**，宠物跑得越快、腿摆得越宽、跳得越高、扬尘越密——横盘时安安静静，行情狂奔时它也狂奔。
- **拟人造型**：会奔跑的牛，以及熊大风格的**直立拟人熊**（红棕毛、白胸带、大圆鼻、绿眼红耳）。
- **可拖动、可收起**：按住宠物可拖到窗口任意位置；不拖动地**单击**则开关自选面板。
- **自选面板**：逐只列出自选的最新红/绿涨跌，底部显示组合平均，可按名称/代码搜索添加、删除。
- **🏁 行情赛跑**：面板顶部一条"赛道"，每只自选一根进度条，**长度与其涨跌幅成比例**——涨幅最大者占满跑道，其余按相对比例缩放。
- **可应对大量标的**：最多 200 只，按每片 500 只分片抓取，避开新浪单 URL 上限。

## 安装

```bash
# npm 包（预构建，推荐）
dsh plugin --profile web add dsh-bull-bear

# 或本地目录
dsh plugin --profile web add /path/to/dsh-bull-bear
```

添加后重启一次 `dsh web`，刷新页面即可看到左下角的牛/熊宠物。

## 使用

- **拖动**：鼠标按住宠物，拖到窗口任意位置后松开，宠物留在原位（当前会话保持）。
- **开关面板**：不拖动地单击宠物，右侧的自选面板展开/收起。
- **自选面板**：
  - 每行显示股票名称与最新涨跌，配色遵循 A 股习惯——**红=涨、绿=跌**。
  - **搜索框**输入名称或代码（如 `茅台`、`600519`），下方出现匹配结果，点击即添加。
  - 行尾的 `✕` 删除该自选。
  - 底部**组合平均**同样红/绿显示。
  - 改动写入 `<workspace>/.bull-bear-watchlist.json`，启动时重新应用（最多 200 只）。
- **🏁 行情赛跑**：面板最上方的赛道，按涨跌排序列出前 6 名自选；每根进度条宽度**以当前最大涨幅为满幅**，其余按相对比例缩放——一眼看出谁的涨幅量级最大。

### 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `symbols` | 上证/深成/创业板/茅台/宁德 | 自选标的（新浪代码，如 `sh000001`、`sz399001`；支持 `6` 开头自动识别为沪市） |
| `refreshMs` | `5000` | 行情刷新周期（毫秒） |
| `sensitivity` | `1` | 速率→抬/低头角度放大倍数（`0.1`–`5`） |

主代码默认值在 `src/index.js` 的 `config` 对象中；运行期可通过 RPC 动态调整。

## 原理

- **Host 半**（`src/index.js`）：每 `refreshMs` 用原生 `fetch` 请求新浪 `hq.sinajs.cn`，GBK 解码，计算每个标的相对昨收的涨跌幅（`pct`）与其速率，再求**组合平均**（`avgPct`、`avgRate`）。新浪对超过约 800 只的一个 URL 会返回 HTTP 431，因此按**每片 500 只分片并发**抓取后合并。另有 `search` 操作经腾讯 `smartbox` 按名称/代码解析证券。全部通过官方 `ctx.connection.rpc.handle('/bullbear'...)` 通道暴露。
- **Client 半**（`src/client/index.js`）：轮询 RPC，由 `|avgPct| / 20` 推导一个封顶的 **vigor**（市场强度），缩放奔跑速度、腿摆幅度、跳跃高度与扬尘浓度；动画循环逐帧驱动四肢。面板与赛道读取同一份数据。注册进 `shell.overlay` 槽位。

窗口内 `mood` 判定：组合 `avgPct > 0.05` 显示牛、`avgPct < -0.05` 显示熊、其余横盘。
